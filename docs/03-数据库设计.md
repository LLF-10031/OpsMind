## 一、实体关系总览

```
host ──1:N── task ──1:N── task_run ──1:N── run ──1:1── report
               │
          task_script(N:N)
          template（方案库，不绑主机）
```

|---|---|---|

## 四、索引设计原则

- 多表 `is_deleted` 软删过滤：联合索引 `(业务字段, is_deleted)` 或分区
- `task_run` 按 `task_id` 查历史：`(task_id, started_at DESC)`
- `run` 按 `task_run_id` 查：`(task_run_id)`
- `run` 按脚本+主机查趋势：`(script_id, host_id, created_at DESC)`
- pgvector 向量索引：`embedding` 使用 ivfflat（lists 参数按数据量调）
