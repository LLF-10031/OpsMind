# OpsMind 测试验收指南

## 运行测试

```bash
# 后端（需在 venv 中）
cd backend
pip install -e ".[dev]"
pytest -x -v

# 前端
cd frontend
npm install
npm run build
```

## 验收清单

### 0. 环境就绪
- [ ] PostgreSQL 16 + pgvector 运行中
- [ ] `backend/.env` 已配置（复制 `.env.example` 后修改）
- [ ] 后端启动：`uvicorn app.main:app --reload`（端口 8000）
- [ ] 前端构建：`npm run build`（输出 `dist/`）
- [ ] 执行器启动：`python -m app.executor.server`（端口 8003）

### 1. 认证
- [ ] 访问 `/login` 跳转正常
- [ ] 输入密码登录，获取 token
- [ ] 刷新页面后保持登录态（/verify 自动校验）
- [ ] 登出正常

### 2. 主机管理
- [ ] 主机 CRUD（增/删/改）
- [ ] 探测按钮返回连通状态
- [ ] 主机详情弹窗显示绑定任务

### 3. 脚本库
- [ ] 脚本 CRUD
- [ ] 试跑：选主机后执行，返回结果
- [ ] LLM 预览：输入样本输出，显示判定结果
- [ ] 跟踪指标：添加/启用/删除/预览
- [ ] 趋势：查看历史 + 各指标序列 + LLM 趋势总结（需 LLM key）

### 4. 模板库
- [ ] 模板 CRUD（含脚本绑定）
- [ ] 应用模板：选主机 → 生成任务

### 5. 知识库
- [ ] 上传文档（支持 .md/.txt/.pdf）
- [ ] 文档详情 + 知识单元预览
- [ ] 搜索：输入词 + 文档限定/全库模式
- [ ] 删除文档

### 6. 巡检任务
- [ ] 任务 CRUD（绑定脚本、调度 JSON）
- [ ] 编辑保留脚本绑定（回归：修复前清空）
- [ ] 切换启用/停用
- [ ] 立即执行 → 生成 task_run

### 7. 任务看板
- [ ] SSE 实时推送（run_result / batch_ready / done）
- [ ] 重新分析按钮
- [ ] 原始输出（关键词过滤）
- [ ] 停止任务（协作式，当前脚本结束后中止）

### 8. AI 助手
- [ ] 会话 CRUD + 重命名
- [ ] 流式对话（kb_ready / token / done）
- [ ] 知识库文档勾选检索
- [ ] 消息分页：加载更早消息
- [ ] 保存为记忆（弹窗 → topic + summary）

### 9. 评估
- [ ] 案例 CRUD + 预期级别设定
- [ ] 运行评估（勾选/全部）
- [ ] 结果历史 + 详情弹窗（雷达图条形）

### 10. 记忆
- [ ] Episodic / Semantic 双 tab
- [ ] CRUD + 编辑
- [ ] Semantic 查询

### 11. 报告
- [ ] 全局报告列表（级别/类型/脚本筛选）
- [ ] 报告详情弹窗（AI 分析内容 / 标注）

### 12. 仪表盘
- [ ] 统计卡片（主机/任务/脚本/文档）
- [ ] 近期巡检批次列表
- [ ] 近期告警列表

### 13. 系统设置
- [ ] LLM 配置读写
- [ ] API Key 掩码保存

## 边界情况

- SSE 断连：看板应自动重连（非永久 error）
- 空状态：各表格在无数据时显示友好提示
- Token 过期：自动跳转登录页
- 分页：消息/报告列表支持翻页
